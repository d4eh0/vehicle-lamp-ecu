# HW/SW 인터페이스

상태: 배정 후보. 최종 `.ioc`·KiCad 회로와 대조 전 미확정.

| 항목 | 경계 조건·후보 | 관련 요구사항 |
|---|---|---|
| CAN | STM32 PB8 RX·PB9 TX 리맵 후보. UNO Q D4 TX·D5 RX 후보. 실제 헤더·다중 기능 충돌 확인 필요 | SWR-001 / HWR-002~003 |
| 램프 출력 | 6논리 채널, TAIL_STOP_L/R의 PWM 필요. 핀·타이머·출력 극성 미정 | SWR-004~012 / HWR-004~006 |
| 초기 출력 | SW 초기화 이후 OFF, 리셋 중 하드웨어 기본 OFF | SWR-012 / HWR-005 |
| 진단 | UART 전압·핀·프로토콜, 온보드 LED 핀·극성 미정 | SWR-015~018 / HWR-007 |
| 개발 | SWD 유지. 전원 공급 경로·공통 GND·입출력 전압 검토 | HWR-001~002,007 |

변경 영향: 핀·클럭·타이머 변경 → CubeMX·펌웨어·KiCad 회로도·해당 시험 설정 동시 확인.
