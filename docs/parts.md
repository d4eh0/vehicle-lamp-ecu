## 3. 이번 후방 램프 ECU 추가 주문

**주문 내역 확인 필요.** 최근 미소파츠 스토어의 구매 후보는 논의했지만 실제 주문한 품목·수량·가격이 확인되지 않았다. 아래 항목을 임의로 '구매 완료'로 표시하지 않는다.

| 품목 | 수량 | 주문처 | 주문 상태 |
|---|---:|---|---|
| 최근 추가 구매 품목 | 미확인 | 미소파츠 스토어(계획) | 주문 내역 미확인 |

## 4. 설계상 필요한 추가 부품 (구매 여부 미확인)

| 품목 | 용도 | 상태 |
|---|---|---|
| 3.3V MCU 호환 CAN 트랜시버 × 2 | UNO Q ↔ STM32 Classical CAN 버스 | 보유/주문 확인 필요 |
| CAN 종단저항 120Ω × 2 | 버스 양 끝 종단 | 보유/구매 확인 필요 |
| LED 구동 소자·저항·램프용 LED | 6개 논리 출력 채널 | 보유 수량·정격 확인 필요 |
| 외장 CAN FD 컨트롤러 + FD 트랜시버(또는 FDCAN MCU) | CAN FD 확장 | **선택 확장, 구매 미확정** |

예시로 검토했던 SN65HVD230은 Classical CAN용 트랜시버 후보이며, 이것만으로 STM32F103에 CAN FD 기능이 생기지 않는다. 외장 MCP2518FD는 CAN FD **컨트롤러**이고 별도 호환 트랜시버가 필요할 수 있다.

> 실제 주문 영수증이나 상품 목록이 확보되면 3절의 모델·수량·구매처를 갱신한다. 추천품과 보유품, 실제 구매품은 구분한다.
