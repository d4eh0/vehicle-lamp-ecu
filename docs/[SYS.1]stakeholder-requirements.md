# SYS.1 — 후방 램프 ECU 요구사항

![후방 램프 ECU 시스템 컨텍스트](../diagrams/%5BSYS.1%5Dsystem-context.svg)

[다이어그램 편집 원본](../diagrams/%5BSYS.1%5Dsystem-context.drawio)

## 1. 무엇을 개발할 것인가?

차량 **후방 램프를 제어하는 독립 ECU**를 개발한다. BCM에서 램프를 직접 구동하는 방식 대신, BCM이 전달한 명령을 후방 램프 ECU가 처리하는 구조를 채택한다.

| 항목 | 적용 범위 | 선정 이유 |
|---|---|---|
| 제어 대상 | 후방 램프 | 전방까지 확장하지 않고 후방 조명 기능과 검증에 집중 |
| 제어 구조 | BCM → CAN → 후방 램프 ECU → LED | ECU 간 통신과 램프 제어 소프트웨어를 분리 |
| 통신 | Classical CAN | CAN FD는 확장 대상으로 구분 |

프로토타입에서는 **Arduino UNO Q가 BCM을 모사**하고, **STM32F103C8T6이 후방 램프 ECU의 MCU** 역할을 맡는다.

| 포함 기능 | 제외 기능 |
|---|---|
| 좌·우 방향지시등, 비상등 | 전방 방향지시등·전조등·DRL |
| 미등, 제동등, 후진등, CHMSL | 자동 미등(AUTO) |
| CAN 제어 명령, 시험용 오류 처리 | 전체 변속기 모델, 실제 LED 고장 검출 |

## 2. 무엇을 할 수 있어야 하는가?

### 기능 요구사항

| ID | 기능 | 요구사항 |
|---|---|---|
| STK-001 | 제어 명령 | 후방 램프 ECU는 BCM에서 전달한 램프 제어 명령에 따라 동작해야 한다. |
| STK-002 | 방향지시 | 좌·우 후방 방향지시등을 각각 제어해야 한다. |
| STK-003 | 비상등 | 비상등 요청 시 좌우 방향지시등이 함께 점멸하며 일반 방향지시보다 우선해야 한다. |
| STK-004 | 점멸 | 방향지시등과 비상등은 일정한 주기로 점멸해야 한다. |
| STK-005 | 미등·제동등 | 공용 램프에서 미등과 제동등을 구분하고 제동 요청을 우선해야 한다. |
| STK-006 | 보조제동등 | 중앙 보조제동등(CHMSL)은 브레이크 요청에 따라 독립적으로 점등해야 한다. |
| STK-007 | 후진등 | 후진 요청에 따라 후진등을 제어하고 다른 램프와 함께 작동할 수 있어야 한다. |
| STK-008 | 시동 상태 | 시동 상태에 따라 허용되는 램프 기능을 구분해야 한다. |
| STK-009 | 상태 유지 | 시동 상태가 변경돼도 비상등 상태와 유지형 입력을 올바르게 반영해야 한다. |
| STK-010 | 초기화 | ECU 초기화 중 의도하지 않은 램프 점등을 방지해야 한다. |
| STK-011 | 비정상 명령 | 유효하지 않은 램프 명령을 처리하고 다른 정상 기능에 미치는 영향을 제한해야 한다. |
| STK-012 | 진단 | 시험용 고장 주입·해제와 오류 기록 기능을 제공해야 한다. |
| STK-013 | 통신 오류 | CAN 명령 누락이나 오류를 감지하고 대응해야 한다. |
| STK-014 | 입력 조작 | BCM 시뮬레이터는 시동·레버·비상등·미등·브레이크·후진 입력을 전달해야 한다. |
| STK-015 | 전원 | 시동 OFF에서도 허용된 램프 기능을 사용할 수 있어야 한다. |
| STK-016 | 검증 | 램프 제어 로직과 실제 ECU 출력을 SIL 및 HIL로 검증할 수 있어야 한다. |

### 조작 입력

| 입력 | 동작 |
|---|---|
| IGN | ON / OFF |
| 방향 레버 | 위=우 / 중앙=OFF / 아래=좌 |
| 비상등 | 누를 때마다 ON/OFF 전환 |
| 미등 | ON / OFF |
| 브레이크 | 누름 / 해제 |
| 후진 | R / NOT R |

## 3. 어떤 조건과 제약을 만족해야 하는가?

### 운용 조건

| 항목 | 조건 |
|---|---|
| IGN OFF | 비상등·미등·제동등 허용, 일반 방향지시등·후진등 차단 |
| 우선순위 | 비상등은 방향지시등보다 우선하고, 제동등은 미등보다 우선 |
| 기능 독립성 | 후진등과 보조제동등은 다른 램프 기능과 구분해 제어 |
| 초기화 | ECU 초기화 중 출력 OFF, 이후 유효한 제어 명령 반영 |
| 비정상 상황 | 통신 오류 및 시험용 가상 고장에 대한 처리가 필요 |

### 개발 제약

| 항목 | 적용 |
|---|---|
| ECU MCU | STM32F103C8T6 |
| BCM 시뮬레이터 | Arduino UNO Q |
| 기본 통신 | Classical CAN |
| 통신 확장 | CAN FD 별도 검토 |
| 검증 | PC SIL 및 실물 HIL |
