# SWE.1 소프트웨어 요구사항

상태: 검토 초안. 구현·시험 결과 제외.
입력: [프로젝트 기능 목표·실행 환경](project-scope.md).
대상: STM32에서 실행되는 램프 제어 소프트웨어. BCM 입력 처리·전원 회로 책임과 구분.

| ID | 조건·필수 동작 | 프로젝트 입력 | 예정 확인 방법 |
|---|---|---|---|
| SWR-004 | IGN ON·HAZARD OFF: LEFT는 좌측만, RIGHT는 우측만 점멸. TURN OFF는 양쪽 소등 | PRJ-002,008 | 입력 조합별 좌우 출력 검사 |
| SWR-005 | HAZARD ON: IGN·TURN과 관계없이 좌우 동기 점멸. IGN 변경에 따른 HAZARD 상태 변경 금지 | PRJ-003,008,009 | 비상등 중 IGN·TURN 변경 검사 |
| SWR-007 | 점멸 모드 전환 시 일관된 시작 동작, 비상등 해제 시 현재 IGN·TURN 복귀 | PRJ-003,004,009 | 전환·복귀 검사 |
| SWR-008 | 공용 미등·제동 출력에서 제동 우선, CHMSL은 제동 요청에만 반응 | PRJ-005,006 | 입력 조합별 출력 검사 |
| SWR-010 | IGN ON·REVERSE=1일 때만 후진 출력 ON. 다른 허용 기능과 동시 동작 | PRJ-007,008 | 입력 조합·동시 요청 검사 |
| SWR-011 | IGN OFF: 일반 방향지시·후진 OFF, 비상등·미등·제동 허용. IGN ON 복귀 시 최신 TURN·REVERSE 적용 | PRJ-008,009,015 | IGN 전환 전후 출력 검사 |
| SWR-012 | SW 출력 제어 가능 시점부터 최초 유효 명령 전까지 6채널 OFF. 리셋 중 기본 OFF는 회로 조건 | PRJ-010 | 초기화 경로 확인 및 부팅 출력 관측 |

미결 항목: UART 명령·진단 LED 간격·핀/타이머·실제 계측 방법.
