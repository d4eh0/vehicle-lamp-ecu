# HWE.1 외부 회로 요구사항

대상: 보유 개발보드·트랜시버·LED 구동부의 외부 연결 회로. MCU 내부 회로·커스텀 PCB 제외.
상태: 초안. 실제 모듈 사양·부하·전원 확인 전 기준선 미설정.

| ID | 조건·필수 동작 | 프로젝트 입력 | 확인 방법 |
|---|---|---|---|
| HWR-001 | IGN OFF에서도 ECU와 통신 회로 전원 유지 | PRJ-015 | 전원 구성·실측 |
| HWR-002 | MCU와 CAN 트랜시버의 논리 전압·전원 호환, CANH/CANL·공통 기준 전위 연결 | PRJ-001,014 | 부품 자료·연결 회로 검토 |
| HWR-003 | CAN 버스 양 끝 120 Ω 종단, 모듈 내장 종단 포함 중복 검토 | PRJ-001,013 | 무전원 저항·배선 확인 |
| HWR-004 | 램프 논리 출력 6채널 독립 제어 경로, 두 TAIL_STOP 채널 PWM 지원 | PRJ-002~007 | 회로도·핀 배정 검토 |
| HWR-005 | MCU 리셋·고임피던스 시 의도하지 않은 램프 점등 방지 | PRJ-010 | 구동 극성·기본 OFF 회로 검토 |
| HWR-006 | 실제 LED 정격과 MCU 핀 허용 조건에 맞는 전류 제한·구동부 | PRJ-002~007 | LED·MCU 자료, 저항·구동 전류 계산 |
| HWR-007 | SWD 다운로드·디버깅 및 UART 진단·관측 경로 확보 | PRJ-012,016 | 헤더·전압·핀 충돌 검토 |

우선순위: HWR-001~007 필수.
미결: 개발보드 회로·헤더, 트랜시버 모듈 내장 종단, LED별 전압·전류, 전원 공급원, 구동 극성.
영향: 핀·타이머·리셋 기본 상태와 전압 조건은 SW 출력 극성·초기화·CubeMX 설정에 직접 영향.
회로 제작·계측은 예정. 위 확인 방법은 수행 결과 아님.
