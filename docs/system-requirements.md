# [SYS.2] 후방 램프 ECU 시스템 요구사항

## 1. 시스템 개요

```text
물리 스위치 → Arduino UNO Q (BCM 시뮬레이터)
                            │ LAMP_COMMAND / Classical CAN
                            ▼
                       STM32F103C8T6 (Rear Lamp ECU)
                            │ GPIO / PWM
                            ▼
                       후방 램프 6개 출력
```

개발 대상은 **Rear Lamp ECU**이다. UNO Q는 외부 BCM 시뮬레이터로 사용하며, ECU는 수신한 조작 상태에 따라 램프를 제어한다.

| 구분 | 내용 |
|---|---|
| CAN 입력 | IGN, TURN, HAZARD, TAIL, BRAKE, REVERSE |
| 램프 출력 | TURN_L, TURN_R, TAIL_STOP_L, TAIL_STOP_R, REVERSE_LAMP, CHMSL |
| 통신 | Classical CAN |
| 검증 | PC SIL · 실물 HIL |

## 2. 주요 검증 기준

| 대상 | PASS 기준 | 요구사항 |
|---|---|---|
| 방향지시·비상등 | 좌우 개별·동기 점멸 및 비상등 우선, 해제 후 원래 레버 상태 복귀 | SYS-001~005 |
| 점멸 주기 | ON/OFF 구간 각각 400±20ms | SYS-004 |
| 미등·제동등 | 미등 20±2%p PWM(1kHz±5%), 제동 100%, CHMSL 독립 점등 | SYS-008~009 |
| 시동·후진 | IGN OFF 시 방향지시·후진 차단, 비상등·미등·제동 허용 | SYS-010~014 |
| 응답시간 | 유효 CAN 수신→ECU 출력 ≤10ms, 물리 조작→출력 ≤50ms | SYS-006~007 |
| CAN 검증 | 유효하지 않은 명령 무시, 50ms 주기 명령 수신, 200ms 무수신 판정 | SYS-021~024 |

응답시간은 **출력을 실제 변경하는 신규 요청**을 정상 통신·무고장 조건에서 측정한다. 검증 기준은 시험 목표이며 측정 결과가 아니다.

## 3. 램프 동작 및 응답시간

### 방향지시등·비상등

| ID | 시스템 요구사항 | 상위 요구 |
|---|---|---|
| SYS-001 | IGN ON, HAZARD OFF에서 TURN=LEFT이면 TURN_L만, TURN=RIGHT이면 TURN_R만 점멸해야 한다. TURN=OFF이면 두 출력은 OFF여야 한다. | STK-002, STK-008 |
| SYS-002 | ECU는 수신된 HAZARD=ON/OFF 상태를 램프 제어에 반영해야 한다. | STK-003 |
| SYS-003 | HAZARD=ON이면 IGN과 TURN 상태에 관계없이 TURN_L/R이 같은 위상으로 점멸해야 한다. HAZARD는 일반 방향지시 요청보다 우선한다. | STK-003, STK-008 |
| SYS-004 | 정상 연속 점멸에서 ON과 OFF 시간은 각각 400±20ms여야 한다. 모드 전환으로 잘린 구간은 이 기준에서 제외한다. | STK-004 |
| SYS-005 | 활성 점멸 모드가 바뀌면 해당 출력은 ON으로 시작하며 점멸 타이머를 초기화해야 한다. HAZARD 해제 후 유효한 TURN 요청이 남아 있으면 해당 방향지시등으로 자동 복귀해야 한다. | STK-003, STK-004, STK-009 |

### 미등·제동등·후진등

| ID | 시스템 요구사항 | 상위 요구 |
|---|---|---|
| SYS-008 | ECU는 TAIL/BRAKE의 네 가지 입력 조합에서 아래 진리표대로 TAIL_STOP_L/R와 CHMSL을 제어해야 한다. | STK-005, STK-006 |
| SYS-009 | 미등만 ON일 때 TAIL_STOP_L/R의 PWM은 듀티 18~22%, 주파수 950~1050Hz여야 한다. BRAKE=ON이면 연속 ON(100%)으로 전환해야 한다. | STK-005 |
| SYS-010 | IGN=ON, REVERSE=1이면 REVERSE_LAMP를 ON하고 REVERSE=0이면 OFF해야 한다. 다른 허용된 램프 기능과 동시 작동할 수 있어야 한다. | STK-007 |
| SYS-011 | IGN=OFF이면 일반 방향지시등과 후진등을 OFF해야 한다. HAZARD·TAIL·BRAKE 및 CHMSL은 해당 명령에 따라 작동할 수 있어야 한다. | STK-008 |
 
**미등·제동등 출력표**

| TAIL | BRAKE | TAIL_STOP_L/R | CHMSL |
|---|---|---|---|
| 0 | 0 | OFF | OFF |
| 1 | 0 | PWM 20%, 1kHz | OFF |
| 0 | 1 | ON(100%) | ON |
| 1 | 1 | ON(100%) | ON |

### 시동·초기화·입력 검증

| ID | 시스템 요구사항 | 상위 요구 |
|---|---|---|
| SYS-012 | ECU는 IGN 상태 변화만으로 수신된 HAZARD ON/OFF 상태를 변경하지 않아야 한다. | STK-009 |
| SYS-013 | ECU는 IGN=OFF에서 IGN=ON으로 전환되면 최신 유효 CAN 명령의 TURN 및 REVERSE 값을 별도 재조작 없이 반영해야 한다. | STK-009 |
| SYS-014 | ECU는 IGN=OFF에서도 전원이 유지되어 허용된 조명 명령을 처리할 수 있어야 한다. | STK-015 |
| SYS-015 | ECU는 초기화 중 출력을 OFF로 유지하고, 초기화 완료 후 첫 유효 CAN 명령에 따라 제어를 시작해야 한다. | STK-010 |
| SYS-016 | TURN=3 등 잘못된 신호 값을 포함한 명령 전체는 무효로 처리하고 오류를 기록해야 한다. 이미 수신한 정상 명령에 따른 제어는 통신 두절 조건이 발생하기 전까지 유지한다. | STK-011, STK-013 |

### 응답시간

| ID | 시스템 요구사항 | 상위 요구 |
|---|---|---|
| SYS-006 | 정상 조건에서 유효한 CAN 프레임 수신 완료 후 해당 램프 출력의 최초 변경까지 10ms 이내여야 한다. | STK-002, STK-003, STK-016 |
| SYS-007 | 정상 조건에서 유효한 물리 스위치 조작부터 해당 램프 출력의 최초 변경까지 50ms 이내여야 한다. | STK-002, STK-003, STK-016 |

## 4. CAN 인터페이스

### LAMP_COMMAND

| 신호 | 정상 값 |
|---|---|
| IGN | 0=OFF, 1=ON |
| TURN | 0=OFF, 1=LEFT, 2=RIGHT |
| HAZARD | 0=OFF, 1=ON |
| TAIL | 0=OFF, 1=ON |
| BRAKE | 0=해제, 1=제동 |
| REVERSE | 0=NOT R, 1=R |

`TURN=3` 및 정의되지 않은 값은 유효하지 않은 명령으로 처리한다. 유효성 검사를 통과한 **메시지 전체의 상태**를 적용하며, 일부 필드만 갱신하지 않는다.

BCM 인터페이스 입력 조건: **상태 변경 즉시 전송 + 50ms 주기 전송**. CAN ID·DLC·신호의 비트 위치와 통신 속도는 인터페이스 상세 설계에서 지정한다.

### CAN 및 상태 동기화 요구사항

| ID | 시스템 요구사항 | 상위 요구 |
|---|---|---|
| SYS-021 | ECU는 `LAMP_COMMAND`의 여섯 상태 신호를 수신하여 램프 제어에 반영해야 한다. | STK-001, STK-014 |
| SYS-022 | ECU는 수신 CAN ID, DLC 및 신호 값을 검사해야 한다. 유효하지 않은 메시지 전체를 무시하고 마지막 유효 수신 시각을 갱신하지 않아야 한다. | STK-001, STK-011, STK-013 |
| SYS-023 | 마지막 유효 `LAMP_COMMAND` 수신 후 200ms 동안 유효한 메시지가 없으면 ECU는 통신 두절로 판정하고 후방 램프 6개 출력을 OFF해야 한다. | STK-013 |
| SYS-024 | ECU는 BCM이 상태 변경 시 즉시, 평상시 50ms 간격으로 보내는 동일한 상태 메시지를 처리해야 한다. | STK-001, STK-014 |
| SYS-025 | ECU는 부팅 중 및 최초 유효 CAN 메시지 수신 전 모든 램프 출력을 OFF로 유지해야 한다. | STK-010 |
| SYS-026 | ECU는 통신 복구 또는 재부팅 후 첫 유효 CAN 메시지를 수신하면 그 상태를 적용하여 램프 제어를 재개해야 한다. | STK-009, STK-010, STK-013 |
