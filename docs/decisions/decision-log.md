# Vehicle Lamp ECU — 설계 의사결정 기록

> SYS.2~SYS.5 및 SWE.1~SWE.6 진행 중 결정한 선택·근거·대안·검증 방향을 기록한다.
> 확정되지 않은 동작은 요구사항으로 간주하지 않는다. 추가 의사결정은 `TASK.md`의 대기열에 기록한다.

## D-01 — 구현 범위 선정

- **상태:** 확정
- **결정:** 후방 통합 램프 ECU (좌·우 방향지시등, 비상등, 미등, 제동등, 후진등)
- **비고:** 기능별 세부 동작과 검증 기준은 SYS.2에서 정의한다.

## D-02 — 후진 입력 선정

- **상태:** 확정
- **결정:** 2단 슬라이드 스위치로 `R / NOT R` 상태 입력
- **비고:** P-R-N-D 전체 기어 모델 대신 후진등에 필요한 입력만 표현한다.

## D-03 — 시동과 미등의 관계

- **결정일:** 2026-10-28
- **상태:** 확정 (사용자 선택: B)
- **문제:** 시동 상태와 미등 제어를 연동할지, 별도의 조명 제어 입력을 둘지 정해야 한다.
- **선택:** 시동 입력과 별도의 미등 스위치를 두어 미등 ON/OFF를 독립적으로 제어한다. 조도센서 기반 AUTO 모드는 이번 범위에서 제외한다.
- **대안:** (A) 시동 ON에 미등 자동 연동, (C) 조도센서 기반 AUTO 모드.
- **선택 근거:** 실제 차량의 조명 스위치 개념과 유사한 입력을 모델링할 수 있고, 시동과 미등 입력의 조합을 독립적인 SYS/SWE 요구사항과 SIL/HIL 시나리오로 검증할 수 있다.
- **트레이드오프:** 별도 스위치·입력 채널이 추가된다. 조도 기반 자동 제어는 구현하지 않는다.
- **검증 방향(아직 테스트 미수행):** 시동/미등 스위치의 입력 조합에 대해 정의된 미등 출력 정책을 시험한다.
- **미결 사항:** 시동 OFF일 때 미등 스위치가 ON이면 실제 점등을 허용할지는 D-06에서 확정한다. 입력 스위치의 세부 전기적 구현은 SYS.3에서 확정한다.
