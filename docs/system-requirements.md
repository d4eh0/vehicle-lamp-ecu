# Vehicle Lamp ECU — 시스템 요구사항 (SYS.2)

> **상태: 초안 v0.1 (검토 전).** [D-01~D-14 결정 기록](decision-log.md)을 시험 가능한 시스템 동작으로 정리했다. 구현·측정·PASS 판정은 아직 진행하지 않았다.

## 1. 시스템 범위 및 입출력

- **대상:** STM32F103C8T6 기반 후방 통합 램프 ECU. IGN은 시동 논리 입력이며 MCU 전원은 IGN OFF에서도 유지한다.
- **입력:** IGN(ON/OFF), 방향 레버(위=우/중앙=OFF/아래=좌), 비상등 순간 버튼(토글), 미등 스위치(ON/OFF), 브레이크 순간 버튼(눌림 유지), 후진 슬라이드(R/NOT R).
- **출력:** 좌/우 방향지시등(`TURN_L/R`), 좌/우 미등·제동등 공용(`TAIL_STOP_L/R`), 후진등(`REVERSE_LAMP`), 중앙 보조제동등(`CHMSL`: 적색 LED 3개를 하나의 독립 출력 채널로 구동).
- **시험 장비:** PC에서 SIL로 내부 제어 로직을 검증하고, Arduino UNO Q로 실제 STM32 입출력을 측정하는 Custom HIL을 구성한다.
- **제외:** 자동 미등(AUTO), 전체 P-R-N-D 모델, 실제 LED 단선·단락 자동 감지, 양산 ECU 기능안전 및 인증.

실제 핀 번호, 회로 드라이버, LED 전류·저항, 전원 구성과 GPIO 구동 극성은 **SYS.3**에서 정한다.

## 2. 시스템 요구사항

각 요구사항의 `D-xx`는 [설계 결정 기록](decision-log.md)에 연결된다. **이 표가 간단한 추적성 표도 겸한다.**

### 2.1 방향지시등·비상등

| ID | 요구사항 (시험 가능 조건) | 근거 |
|---|---|---|
| SYS-001 | IGN ON·비상등 OFF에서 레버 위이면 우측만, 아래이면 좌측만 점멸하고 중앙이면 양쪽 방향지시등이 OFF여야 한다. | D-01, D-04 |
| SYS-002 | 비상등 버튼은 유효한 눌림 한 번에 상태를 한 번 토글해야 하며, 누르고 있는 동안 중복 토글해서는 안 된다. | D-04, D-09 |
| SYS-003 | 비상등 ON이면 IGN·레버 상태에 관계없이 좌우 방향지시등이 같은 위상으로 점멸해야 하며 비상등이 방향 레버보다 우선한다. | D-05, D-06 |
| SYS-004 | 안정적으로 계속 점멸 중인 방향지시등/비상등은 ON 구간과 OFF 구간 각각 400±20ms여야 한다. 기능 전환으로 중간에 끊긴 구간은 제외한다. | D-07 |
| SYS-005 | 좌·우 방향지시/비상등 등 활성 점멸 기능이 변경되면 새 점멸 기능은 ON부터 시작하고 타이머를 초기화해야 한다. | D-07 |
| SYS-006 | 이전에 점멸이 OFF이고 비상등이 OFF인 상태에서, IGN ON 시 바운스 없는 방향 레버 입력 변화 후 해당 첫 출력 ON까지 20ms 이내여야 한다. | D-09, D-13 |
| SYS-007 | 비상등 OFF 상태에서 바운스 없는 버튼 누름으로 비상등이 ON되면, 입력 변화부터 좌우 출력이 처음 ON될 때까지 30ms 이내여야 한다. | D-09, D-13 |

### 2.2 미등·제동등·후진등

| ID | 요구사항 (시험 가능 조건) | 근거 |
|---|---|---|
| SYS-008 | IGN과 무관하게 미등·브레이크 입력의 4가지 조합에서 좌우 공용 램프와 CHMSL이 아래 진리표대로 작동해야 한다. | D-03, D-05, D-06, D-10, D-11 |
| SYS-009 | 미등만 ON인 공용 출력의 PWM은 듀티 18~22%(목표 20%), 주파수 950~1,050Hz(목표 1kHz)여야 한다. 브레이크 ON의 100%는 연속 점등이다. | D-11 |
| SYS-010 | IGN ON에서 후진 스위치가 R이면 후진등 ON, NOT R이면 OFF이며 다른 허용된 램프 기능과 동시에 작동해야 한다. | D-02, D-05 |
| SYS-011 | IGN OFF에서는 일반 방향지시와 후진등 출력을 차단하지만, 비상등·미등·제동등·CHMSL은 해당 유효 입력 조건대로 작동해야 한다. | D-06 |

**공용 미등·제동 출력 진리표** (IGN ON/OFF 모두 동일, 가상 고장 없음)

| 미등 | 브레이크 | TAIL_STOP_L/R | CHMSL |
|---|---|---|---|
| OFF | OFF | OFF (0%) | OFF |
| ON | OFF | PWM 20%, 1kHz | OFF |
| OFF | ON | 연속 ON (100%) | ON |
| ON | ON | 연속 ON (100%) | ON |

### 2.3 시동·초기화·오류 입력

| ID | 요구사항 (시험 가능 조건) | 근거 |
|---|---|---|
| SYS-012 | MCU 전원이 계속 유지되는 상태에서 IGN OFF/ON 전환만으로 비상등 토글 상태가 바뀌어서는 안 된다. | D-12 |
| SYS-013 | IGN OFF→ON 시 이미 안정된 방향 레버·R 입력은 스위치를 재조작하지 않아도 현재 상태대로 출력에 반영돼야 한다. | D-12 |
| SYS-014 | IGN OFF에도 MCU는 전원이 공급되어 허용된 비상등·미등·제동등을 처리할 수 있어야 한다. | D-06, D-12 |
| SYS-015 | MCU 초기화 중 모든 램프 출력은 OFF여야 한다. 초기화 후 현재 물리 입력을 재평가하지만 비상등 토글은 OFF에서 시작해야 한다. | D-08 |
| SYS-016 | 좌/우 방향지시 레버 입력이 동시에 활성화되면 일반 방향지시 요청을 무효 처리하고 오류를 기록해야 한다. 비상등과 다른 정상 램프 기능은 유지해야 한다. | D-08 |

### 2.4 시험용 가상 고장

| ID | 요구사항 (시험 가능 조건) | 근거 |
|---|---|---|
| SYS-017 | 시험 빌드에서 UNO Q의 UART 명령으로 지정 출력에 가상 고장을 설정/해제할 수 있어야 한다. SIL은 UART 없이 동일한 내부 고장 처리 로직을 호출한다. | D-08, D-14 |
| SYS-018 | 가상 고장으로 지정한 출력 채널만 강제로 OFF 처리하고, 다른 정상 채널 출력은 기존 규칙대로 유지해야 한다. | D-14 |
| SYS-019 | 가상 고장 상태는 명시적 CLEAR 명령까지 유지하고, 해제하면 현재 유효 입력에 따라 해당 출력 상태를 재평가해야 한다. | D-14 |
| SYS-020 | 오류 이벤트는 코드·채널·발생/해제·시간을 포함해 RAM에 최근 16건까지 기록하고, 초과 시 오래된 이력을 덮어써야 한다. MCU 재부팅 시 RAM 오류 이력과 가상 고장 상태는 초기화돼야 한다. | D-08, D-14 |

> SYS-017~020은 **테스트를 위한 고장 모사**이며, 실제 LED 고장 감지나 실차의 안전 상태를 증명하지 않는다.

## 3. 소프트웨어 단계(SWE.1)로 넘길 구현 세부 기준

SYS.2는 외부에서 확인 가능한 결과를 중심으로 작성했다. 내부 처리 방식은 **SWE.1**에서 요구사항으로 구체화한다.

| 이미 결정한 SW 세부 기준 | 근거 |
|---|---|
| 비상등·IGN 20ms, 방향 레버·미등·후진 10ms, 브레이크 5ms의 Non-blocking 디바운싱 | D-09 |
| 디바운싱 완료 후 점멸 첫 출력 ON 명령까지 SW 10ms 이내 | D-13 |
| 테스트용 UART 진단 명령, RAM 오류 16건 및 CLEAR 처리 | D-14 |
| 점멸 상태머신·우선순위·PWM 타이머·시동 상태 전환 처리 | D-05~D-12 |

## 4. 검증 방향 및 남은 검토

- **SIL(예정):** 입력 조합, 우선순위, 디바운싱·타이밍, 가상 고장 상태와 로그를 PC에서 검증한다.
- **HIL(예정):** UNO Q로 STM32 입력을 생성하고 GPIO 점멸 시간, 첫 점등 시간, PWM 주파수·듀티, 고장 설정·해제를 관측한다.
- **검토 예정:** 요구사항 간 중복·누락, 점멸 기능 전환 중 끊긴 구간의 시험 판정, HIL 측정 해상도/전압 조건(SYS.3). 실제 회로·코드·테스트가 없는 상태에서는 PASS라고 표시하지 않는다.

**SYS.2 완료 조건:** 위 20개 요구사항과 진리표를 검토하여 필요한 수정 후 초안 상태를 '확정'으로 변경한다. 지금은 아직 **미완료**다.
