# Vehicle Lamp ECU — 설계 의사결정 기록

> SYS.2~SYS.5 및 SWE.1~SWE.6 진행 중 결정한 선택·근거·대안·검증 방향을 기록한다.
> 확정되지 않은 동작은 요구사항으로 간주하지 않는다. 추가 의사결정은 `TASK.md`의 대기열에 기록한다.

## D-01 — 구현 범위 선정

- **상태:** 확정
- **결정:** 후방 통합 램프 ECU (좌·우 방향지시등, 비상등, 미등, 제동등, 후진등)
- **비고:** 기능별 세부 동작과 검증 기준은 SYS.2에서 정의한다.

## D-02 — 후진 입력 선정

- **상태:** 확정
- **결정:** 2단 슬라이드 스위치로 `R / NOT R` 상태 입력
- **비고:** P-R-N-D 전체 기어 모델 대신 후진등에 필요한 입력만 표현한다.

## D-03 — 시동과 미등의 관계

- **결정일:** 2026-10-28
- **상태:** 확정 (사용자 선택: B)
- **문제:** 시동 상태와 미등 제어를 연동할지, 별도의 조명 제어 입력을 둘지 정해야 한다.
- **선택:** 시동 입력과 별도의 미등 스위치를 두어 미등 ON/OFF를 독립적으로 제어한다. 조도센서 기반 AUTO 모드는 이번 범위에서 제외한다.
- **대안:** (A) 시동 ON에 미등 자동 연동, (C) 조도센서 기반 AUTO 모드.
- **선택 근거:** 실제 차량의 조명 스위치 개념과 유사한 입력을 모델링할 수 있고, 시동과 미등 입력의 조합을 독립적인 SYS/SWE 요구사항과 SIL/HIL 시나리오로 검증할 수 있다.
- **트레이드오프:** 별도 스위치·입력 채널이 추가된다. 조도 기반 자동 제어는 구현하지 않는다.
- **검증 방향(아직 테스트 미수행):** 시동/미등 스위치의 입력 조합에 대해 정의된 미등 출력 정책을 시험한다.
- **미결 사항:** 시동 OFF일 때 미등 스위치가 ON이면 실제 점등을 허용할지는 D-06에서 확정한다. 입력 스위치의 세부 전기적 구현은 SYS.3에서 확정한다.

## D-04 — 조작 입력 방식

- **결정일:** 2026-10-28
- **상태:** 확정 (사용자 선택)
- **문제:** 3단 레버와 각 버튼의 물리 조작을 차량 램프 제어 명령에 어떻게 매핑할지 정의한다.
- **결정 1 — 방향지시 레버:** 위=우회전, 중앙=OFF, 아래=좌회전. 레버 위치가 유지되는 3단 입력으로 모델링한다.
- **결정 2 — 브레이크:** 버튼을 누르고 있는 동안만 제동 요청을 활성화하며, 놓으면 해제한다.
- **결정 3 — 비상등:** 버튼을 누를 때마다 비상등 상태가 ON/OFF 전환되는 토글 동작을 채택한다.
- **선택 근거:** 레버 위치, 제동 페달의 지속 입력, 비상등의 토글 조작을 분리해 현실적인 입력 상태와 재현 가능한 SIL/HIL 시험 시나리오를 확보한다.
- **대안과 트레이드오프:** 방향 레버의 위/아래를 반대로 매핑할 수 있으나 일반적인 차량 조작에 맞춘 방향을 선택했다. 브레이크·비상등을 모두 단순 토글 또는 눌림 유지 방식으로 처리하는 대안은 실제 조작 특성과 맞지 않아 제외했다. 비상등 토글은 접점 바운스로 인한 중복 전환 위험이 있다.
- **검증 방향(미수행):** 레버의 3개 고정 위치, 브레이크 누름/해제, 비상등 연속 누름의 입력-상태 변화를 SIL 및 HIL에서 확인한다.
- **추가 결정 대기열:** D-09 — 디바운싱 적용 범위·방식·시간 및 버튼 1회 누름 판정.
- **별도 후속 결정:** 비상등·방향지시등 충돌 시 우선순위는 D-05에서, 시동 OFF 동작은 D-06에서 정한다.
