# Vehicle Lamp ECU — 설계 의사결정 기록

> SYS.2~SYS.5 및 SWE.1~SWE.6 진행 중 결정한 선택·근거·대안·검증 방향을 기록한다.
> 확정되지 않은 동작은 요구사항으로 간주하지 않는다. 추가 의사결정은 `TASK.md`의 대기열에 기록한다.

## D-01 — 구현 범위 선정

- **상태:** 확정
- **결정:** 후방 통합 램프 ECU (좌·우 방향지시등, 비상등, 미등, 제동등, 후진등)
- **비고:** 기능별 세부 동작과 검증 기준은 SYS.2에서 정의한다.

## D-02 — 후진 입력 선정

- **상태:** 확정
- **결정:** 2단 슬라이드 스위치로 `R / NOT R` 상태 입력
- **비고:** P-R-N-D 전체 기어 모델 대신 후진등에 필요한 입력만 표현한다.

## D-03 — 시동과 미등의 관계

- **결정일:** 2026-10-28
- **상태:** 확정 (사용자 선택: B)
- **문제:** 시동 상태와 미등 제어를 연동할지, 별도의 조명 제어 입력을 둘지 정해야 한다.
- **선택:** 시동 입력과 별도의 미등 스위치를 두어 미등 ON/OFF를 독립적으로 제어한다. 조도센서 기반 AUTO 모드는 이번 범위에서 제외한다.
- **대안:** (A) 시동 ON에 미등 자동 연동, (C) 조도센서 기반 AUTO 모드.
- **선택 근거:** 실제 차량의 조명 스위치 개념과 유사한 입력을 모델링할 수 있고, 시동과 미등 입력의 조합을 독립적인 SYS/SWE 요구사항과 SIL/HIL 시나리오로 검증할 수 있다.
- **트레이드오프:** 별도 스위치·입력 채널이 추가된다. 조도 기반 자동 제어는 구현하지 않는다.
- **검증 방향(아직 테스트 미수행):** 시동/미등 스위치의 입력 조합에 대해 정의된 미등 출력 정책을 시험한다.
- **미결 사항:** 시동 OFF일 때 미등 스위치가 ON이면 실제 점등을 허용할지는 D-06에서 확정한다. 입력 스위치의 세부 전기적 구현은 SYS.3에서 확정한다.

## D-04 — 조작 입력 방식

- **결정일:** 2026-10-28
- **상태:** 확정 (사용자 선택)
- **문제:** 3단 레버와 각 버튼의 물리 조작을 차량 램프 제어 명령에 어떻게 매핑할지 정의한다.
- **결정 1 — 방향지시 레버:** 위=우회전, 중앙=OFF, 아래=좌회전. 레버 위치가 유지되는 3단 입력으로 모델링한다.
- **결정 2 — 브레이크:** 버튼을 누르고 있는 동안만 제동 요청을 활성화하며, 놓으면 해제한다.
- **결정 3 — 비상등:** 버튼을 누를 때마다 비상등 상태가 ON/OFF 전환되는 토글 동작을 채택한다.
- **선택 근거:** 레버 위치, 제동 페달의 지속 입력, 비상등의 토글 조작을 분리해 현실적인 입력 상태와 재현 가능한 SIL/HIL 시험 시나리오를 확보한다.
- **대안과 트레이드오프:** 방향 레버의 위/아래를 반대로 매핑할 수 있으나 일반적인 차량 조작에 맞춘 방향을 선택했다. 브레이크·비상등을 모두 단순 토글 또는 눌림 유지 방식으로 처리하는 대안은 실제 조작 특성과 맞지 않아 제외했다. 비상등 토글은 접점 바운스로 인한 중복 전환 위험이 있다.
- **검증 방향(미수행):** 레버의 3개 고정 위치, 브레이크 누름/해제, 비상등 연속 누름의 입력-상태 변화를 SIL 및 HIL에서 확인한다.
- **추가 결정 대기열:** D-09 — 디바운싱 적용 범위·방식·시간 및 버튼 1회 누름 판정.
- **별도 후속 결정:** 비상등·방향지시등 충돌 시 우선순위는 D-05에서, 시동 OFF 동작은 D-06에서 정한다.

## D-05 — 동시 작동 및 출력 우선순위

- **결정일:** 2026-10-28
- **상태:** 확정 (사용자 선택)
- **문제:** 복수 명령이 동시에 활성화될 때 램프 간 출력 충돌과 우선순위를 정해야 한다.
- **결정 1 — 비상등 우선:** 비상등이 활성화되면 좌·우 방향지시등을 동시에 점멸시킨다. 비상등 활성 중 방향지시 레버의 출력 명령보다 비상등 명령이 우선한다.
- **결정 2 — 후방 미등/제동등 공용 LED:** 두 기능은 동일한 LED 출력 채널을 공유하고 PWM으로 밝기를 구별한다. 미등만 켜질 때는 낮은 밝기, 브레이크 입력이 있으면 미등 입력과 무관하게 높은 밝기로 작동한다. 브레이크 해제 후 미등 입력이 남아 있으면 미등 밝기로 복귀한다.
- **결정 3 — 후진등 독립:** R 입력에 따른 후진등은 방향지시등·비상등·미등·제동등과 서로 배타적이지 않으며 동시 작동할 수 있다.
- **선택 근거:** 비상등의 명확한 명령 우선순위, 실제 후방 램프의 미등/제동 겸용 원리, 독립 후진등 동작을 모사한다. 우선순위 충돌과 공용 출력의 복수 입력 조합을 SIL/HIL로 검증할 수 있다.
- **검토한 대안:** 방향지시등 우선 또는 마지막 입력 우선, 미등/제동등을 별도 LED로 분리, 후진 중 타 램프 기능 제한.
- **트레이드오프:** 공용 LED 밝기 제어에는 PWM 구현 및 듀티·주파수·눈에 보이는 밝기 차이 검증이 필요하다. 서로 독립된 기능을 공유 출력에 매핑하므로 미등·제동등 출력 진리표를 명확하게 정의해야 한다.
- **검증 방향(아직 테스트 미수행):** 비상등/방향지시 동시 입력 시 좌우 동기 점멸 확인; 미등·제동 입력 4조합의 공용 LED 출력 단계 확인; R과 타 기능을 동시에 활성화한 상태에서 후진등 출력 확인.
- **미결 사항 및 대기열:** D-10 보조제동등(CHMSL) 중앙 LED 3개 추가 여부; D-11 PWM 밝기·주파수·듀티 및 수용 기준. 둘 다 D-08 완료 후 결정한다. 점멸 타이밍/상태 전환은 D-07에서 결정한다.

## D-06 — 시동 OFF 시 램프 동작 정책

- **결정일:** 2026-10-28
- **상태:** 확정 (사용자 선택: A — 차량 동작 유사형)
- **문제:** 시동이 OFF여도 경고·차량 위치·제동 관련 램프가 필요할 수 있으므로 기능별 입력 처리와 출력 허용 여부를 정의한다.
- **결정:** 시동 OFF 상태에서 비상등, 미등, 제동등은 해당 입력 조건이 충족되면 작동을 허용한다. 방향지시등과 후진등은 명령이 입력되어도 출력을 비활성화한다.
- **동작표:** 비상등=허용 / 미등=허용 / 제동등=허용 / 방향지시등=차단 / 후진등=차단. 허용은 항상 점등한다는 의미가 아니다.
- **기존 결정과의 관계:** D-03의 별도 미등 스위치 정책을 유지한다. D-05의 비상등 우선 및 공용 미등·제동등 PWM 제어도 유지하되, 시동 OFF의 출력 허용 조건을 먼저 적용한다.
- **선택 근거:** 주차 중 비상등·미등 사용 및 시동 정지 상태에서의 브레이크 입력을 모사하고, 시동 상태에 따른 출력 제한을 요구사항과 SIL/HIL 테스트로 검증할 수 있다.
- **검토 대안:** 비상등만 허용, 모든 램프를 시동과 무관하게 허용.
- **트레이드오프:** 시동 OFF 시에도 실제 ECU가 작동할 전원 구조가 필요하며, 시동 전환 직후 입력 및 토글 상태를 어떻게 처리하는지 별도 정의해야 한다.
- **검증 방향(미수행):** 시동 OFF에서 기능별 유효 입력을 주고 허용된 세 램프만 동작하는지 검증한다. 방향지시 레버와 R 입력이 들어와도 해당 출력은 차단되는지 확인한다.
- **추가 결정 대기열:** D-12 — 시동 OFF/ON 전환 시 유지 중인 입력 재평가, 토글 상태 보존/초기화, 시동 OFF 전원 공급 조건. D-08 이후 결정하고 세부 전원 구조는 SYS.3에서 설계한다.

## D-07 — 방향지시등·비상등 점멸 및 위상 정책

- **결정일:** 2026-10-28
- **상태:** 확정 (사용자 선택: B / B / A)
- **문제:** 점멸 간격·타이밍 품질과 좌/우 방향지시등 및 비상등 간 전환 시 위상을 일관되게 정의해야 한다.
- **결정 1 — 주기:** 점멸 기능 활성화 시 출력 ON 400 ms, 이어서 OFF 400 ms를 반복한다(완전한 점멸 주기 800 ms, 분당 75회, ON/OFF 비율 50%).
- **결정 2 — 허용 오차:** 정상 연속 점멸 시 각 ON 및 OFF 구간의 실제 길이는 목표 400 ms 대비 ±20 ms(380~420 ms)를 합격 기준으로 한다.
- **결정 3 — 기능 전환:** 좌/우 방향지시등 및 비상등 등 활성 점멸 기능이 다른 점멸 기능으로 변경되는 시점에는 기존 타이밍 상태를 버리고 새 기능을 ON 상태로 시작하며 점멸 타이머를 초기화한다. 비상등 우선순위는 D-05를 따른다.
- **대안:** 500 ms ON/OFF(60회/분), 300 ms ON/OFF(100회/분); 오차 ±10 ms 또는 ±50 ms; 이전 위상을 유지하는 방식.
- **선택 근거:** 400/400 ms는 육안으로 확인 가능한 규칙적 점멸을 만들고, 기능 전환 시 ON부터 재시작하면 좌우 출력 동기화와 SIL/HIL 기대 결과를 명확히 정의할 수 있다. ±20 ms는 프로젝트에서 정한 정량적인 검증 기준이다.
- **트레이드오프:** 위상 리셋은 전환 순간 ON/OFF 구간 길이를 끊을 수 있다. 따라서 전환 중 잘린 구간과 안정적인 연속 점멸 구간을 검증 시 구분해야 한다. 실제 MCU 스케줄링·GPIO 출력 측정을 통해 ±20 ms 충족 여부를 확인해야 한다.
- **검증 방향(아직 테스트 미수행):** SIL로 380/400/420 ms 경계 조건과 상태 전환 시 타이머 리셋을 검증하고, HIL에서 STM32 실제 GPIO ON/OFF 구간을 측정한다. 비상등 활성 시 좌/우 동기화도 확인한다.
- **미결 사항 및 대기열:** D-13 — 점멸 요청 인식에서 최초 ON까지 허용할 응답 지연 및 SIL/HIL 측정 시작 시점. 이는 연속 점멸 ON/OFF 허용 오차와 별도이다.
- **참고:** 400/400 ms 점멸 타이밍과 미등/제동등 PWM 캐리어 주파수(D-11)는 서로 다른 개념이다.
