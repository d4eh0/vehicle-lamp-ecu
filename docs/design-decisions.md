# 설계 결정

| 항목 | 선택 | 이유·제약 |
|---|---|---|
| 개발 대상 | 후방 램프 제어 SW·외부 연결 회로 | 보유 보드 활용, 6채널 범위 |
| BCM | UNO Q의 입력 해석·토글 상태 소유 | STM32 재부팅 후 주기 명령으로 재동기화 |
| CAN | 한 메시지의 전체 현재 상태 | 신호별 갱신·타임아웃 관리 축소 |
| 전송 | 입력 변경 즉시 + 50 ms 반복 | 반응성과 재동기화 |
| 두절 | 마지막 유효 수신 후 200 ms, 전체 OFF | 시제품 동작 정책. 실제 차량 안전 상태 주장 제외 |
| 점멸 | 모드 변경 시 ON, 반복 명령 시 위상 유지 | 전환·연속 동작 구분 |
| 고장 주입 | 시험 UART의 채널 OFF·CLEAR | 실제 단선·단락 검출 회로 제외 |
| RAM 로그 | 최근 16건, 재부팅 시 초기화 | 비휘발성 기록 제외 |
| 하드웨어 | 실제 개발보드 사양·헤더 기준 | Blue Pill 모델 단정 제외 |
