# SWE.1 소프트웨어 요구사항

상태: 검토 초안. 구현·시험 결과 제외.
입력: [프로젝트 기능 목표·실행 환경](project-scope.md).
대상: STM32에서 실행되는 램프 제어 소프트웨어. BCM 입력 처리·전원 회로 책임과 구분.

|---|---|---|---|
| SWR-001 | BCM의 LAMP_COMMAND CAN 입력 수신·여섯 상태 신호 해석. ID·DLC·비트 배치·속도는 외부 인터페이스 상세 설계 대상 | PRJ-001,014 | 프레임·신호 검사 |
| SWR-002 | TURN=3 등 잘못된 값의 메시지 전체 거부·오류 기록. 일부 신호만 갱신 금지 | PRJ-011,012 | 무효 입력 전후 명령·로그 비교 |
| SWR-003 | 유효 메시지의 여섯 입력·마지막 유효 수신 시각 갱신. 무효 메시지 수신 시 갱신 금지, 두절 전까지 이전 명령 제어 유지 | PRJ-001,011,013,014 | 정상·무효 프레임과 모의 시각 조합 |

| SWR-006 | 연속 점멸 ON·OFF 각각 400±20 ms. 모드 전환으로 잘린 구간 제외 | PRJ-004 | PC 모의 시각 검사 및 보드 파형 측정 |

| SWR-008 | TAIL/BRAKE 조합별 아래 출력표 준수. BRAKE 우선 | PRJ-005,006 | 네 입력 조합 검사 |
| SWR-009 | 미등 단독: 듀티 18~22%·950~1050 Hz. BRAKE ON: 공용 출력 연속 ON | PRJ-005 | PWM 설정·보드 파형 측정 |
| SWR-010 | IGN ON·REVERSE=1일 때만 후진 출력 ON. 다른 허용 기능과 동시 동작 | PRJ-007,008 | 입력 조합·동시 요청 검사 |
| SWR-011 | IGN OFF: 일반 방향지시·후진 OFF, 비상등·미등·제동 허용. IGN ON 복귀 시 최신 TURN·REVERSE 적용 | PRJ-008,009,015 | IGN 전환 전후 출력 검사 |
| SWR-012 | SW 출력 제어 가능 시점부터 최초 유효 명령 전까지 6채널 OFF. 리셋 중 기본 OFF는 회로 조건 | PRJ-010 | 초기화 경로 확인 및 부팅 출력 관측 |
| SWR-013 | 마지막 유효 명령 후 200 ms 무수신 시 통신 두절·6채널 OFF. 무효 프레임 반복에 따른 판정 지연 금지 | PRJ-013 | 모의 시각 경계 검사 및 보드 관측 |
| SWR-014 | 통신 복구 후 첫 유효 명령 적용. 가상 고장 채널 OFF 유지 | PRJ-009,012,013 | 통신 두절·복구와 가상 고장 조합 |
| SWR-015 | 통신 두절 판정 시 진단 LED 5회 점멸·오류 기록. 진단 점멸로 인한 수신·복구 지연 금지 | PRJ-012,013 | 로그·점멸 횟수·점멸 중 복구 검사 |
| SWR-016 | 시험 빌드의 UART 채널 고장 설정·CLEAR, PC 시험의 동일 진단 경로 호출 지원 | PRJ-012 | UART 및 PC 진단 입력 검사 |
| SWR-017 | 가상 고장 채널만 CLEAR 전까지 OFF. 해제 시 최신 명령 재평가, 통신 두절·최초 수신 전이면 OFF 유지 | PRJ-012,013 | 채널별 고장·CLEAR·통신 상태 조합 |
| SWR-018 | 오류 코드·채널·발생/해제·시각의 최근 16건 RAM 저장, 초과 시 오래된 기록 덮어쓰기. 재부팅 시 기록·가상 고장 초기화 | PRJ-012 | 16건 초과 기록·재부팅 검사 |
| SWR-019 | 정상 통신·무고장·출력 변경 신규 요청: 유효 CAN 수신 완료→출력 최초 변경 ≤10 ms | PRJ-002,003,016 | 보드에서 수신·출력 시각 계측 |
