# SWE.4~6 검증 계획

상태: 계획. 펌웨어 시험 결과 없음.

| 단계 | 기준 | 예정 검증 | 산출물 |
|---|---|---|---|
| SWE.4 | 유닛 상세 설계 | 코드 검토·정적 분석·함수 단위 정상/경계/오류 시험 | 유닛별 케이스·결과 |
| SWE.5 | 컴포넌트·SW 아키텍처와 상세 설계 | DBC 수신→명령 갱신→제어→출력 흐름, 통신 두절·진단 상호작용 | 통합 순서·케이스·결과 |
| SWE.6 | SWR-001~019 | 통합 SW 요구사항 기반 시나리오·응답 시간·PWM·부팅·복구 | 요구사항별 케이스·관측값·판정 |

## 실행 환경

| 환경 | 대상·역할 | 한계 |
|---|---|---|
| PC SIL | 실제 제어 C 코드, 모의 시각·CAN 입력·출력 관측 | 전기적 조건·실물 CAN·실제 시간 측정 제외 |
| 실물 보드 | MCU·CAN·GPIO·PWM·UART 동작 및 실제 시간 | LED 육안 확인만으로 정밀 시간 합격 판정 불가 |
| HIL 계획 | 외부 입력 모사·실제 ECU 출력 관측·기대값 비교 | 구동 장비·관측 회로·자동화·모델 상세 설계 미완료 |
| Wokwi | 지원 범위 내 GPIO·LED·PWM 보조 예제 | 실제 CAN·전원·트랜시버·회로 검증 대체 불가 |

HIL은 이번 프로세스 목록과 독립적인 시험 환경. 단순 두 보드 연결을 HIL 완료로 표시하지 않는 기준.

진입: 해당 유닛·컴포넌트·요구사항과 기대값 식별, 실행 코드·환경 버전 확보.
종료: 선택된 범위 실행, PASS/FAIL·미실시 구분, 실패 원인·수정·회귀 결과 기록.
계측 불가능한 시간 항목은 미검증. 테스트 케이스 ID·측정값·성공 결과의 사전 작성 금지.
DBC 오프라인 결과: `can/CAN-interface-check-results.json`. SWE.4~6 펌웨어 결과와 별도 관리.
